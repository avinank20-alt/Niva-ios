# NIVA OS - Quick Start Guide\n\n## Get Running in 5 Minutes\n\n### 1. Install Dependencies\n\n```bash\n# Install Rust nightly\ncurl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain nightly\nsource ~/.cargo/env\n\n# Add x86_64 target\nrustup target add x86_64-unknown-none\n\n# Install QEMU\n# Ubuntu/Debian\nsudo apt-get install qemu-system-x86\n# macOS\nbrew install qemu\n# Fedora\nsudo dnf install qemu-system-x86\n```\n\n### 2. Clone Repository\n\n```bash\ncd /workspaces/Niva-ios\n```\n\n### 3. Build & Run\n\n```bash\n# Build the kernel\nmake build\n\n# Run in QEMU\nmake run\n```\n\n### 4. See It Boot!\n\nYou should see:\n```\n╔════════════════════════════════════════╗\n║       NIVA OS v0.1.0                   ║\n║  Desktop Operating System              ║\n╚════════════════════════════════════════╝\n\n[*] Initializing kernel...\n[*] Setting up GDT...\n[*] Setting up IDT...\n[*] Initializing PIC...\n[*] Enabling interrupts...\n[✓] Kernel initialized successfully!\n\nSystem Information:\n  Architecture: x86_64\n  Mode: Long Mode (64-bit)\n  Platform: NIVA OS\n\nNIVA OS is ready. Initializing desktop environment...\n```\n\n### 5. Exit QEMU\n\nPress: **Ctrl+A**, then **X**\n\n---\n\n## What You Just Ran\n\n✓ **x86_64 Bootloader**\n- Transitions from 32-bit to 64-bit mode\n- Sets up paging and memory\n\n✓ **Kernel Core**\n- Global Descriptor Table (GDT)\n- Interrupt Descriptor Table (IDT)\n- Exception handlers\n- Programmable Interrupt Controller\n\n✓ **Serial I/O**\n- UART 16550 driver\n- Debugging output\n\n---\n\n## Next Steps\n\n### Explore the Code\n```bash\n# Look at the bootloader\ncat src/arch/x86_64/boot.asm\n\n# Look at the kernel entry point\ncat src/main.rs\n\n# Explore module structure\ntree src/\n```\n\n### Modify and Rebuild\n```bash\n# Edit any source file\nvim src/main.rs\n\n# Rebuild\nmake build\n\n# Run again\nmake run\n```\n\n### Debug with GDB\n```bash\n# In one terminal\nqemu-system-x86_64 -m 1G -kernel target/x86_64-unknown-none/release/kernel -s -S -serial stdio\n\n# In another terminal\ngdb target/x86_64-unknown-none/release/kernel\n(gdb) target remote localhost:1234\n(gdb) break kernel_main\n(gdb) continue\n```\n\n---\n\n## Project Structure\n\n```\nNiva-ios/\n├── README.md                    # Ubuntu/Debian\nbrew install make           # macOS\nsudo dnf install make       # Fedora\n```\n\n### \"command not found: cargo\"\n```bash\nsource ~/.cargo/env\n```\n\n### QEMU won't start\n```bash\n# Check if QEMU is installed\nwhich qemu-system-x86_64\n\n# Try running directly\nqemu-system-x86_64 --version\n```\n\n### Build fails with Rust errors\n```bash\n# Update Rust\nrustup update nightly\n\n# Clean and rebuild\ncargo clean\nmake build\n```\n\n---\n\n## Getting Help\n\n1. **Check documentation**\n   - README.md - Overview\n   - BUILDING.md - Build details\n   - ARCHITECTURE.md - Technical design\n   - FEATURES.md - Roadmap\n\n2. **View code comments**\n   - Each file has comments\n   - Module headers explain purpose\n   - Complex functions are documented\n\n3. **Debug with GDB**\n   - Use `make debug`\n   - Set breakpoints\n   - Step through code\n\n4. **Check OSDev resources**\n   - https://wiki.osdev.org/\n   - https://docs.rust-embedded.org/\n\n---\n\n## What's Next?\n\nYou're now running NIVA OS Phase 1!
